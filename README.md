# Portfolio Website

A simple, clean portfolio website with 4 pages: About Me, Projects, Resume, and Contact.

## Files

- **index.html** - Main HTML structure
- **main.js** - Vanilla JavaScript for page navigation and form handling
- **style.css** - Light pink color scheme and responsive design

## How to Use

1. Open `index.html` in a web browser
2. Click navigation links to switch between pages
3. Edit the HTML content to customize with your information
4. Modify colors in the CSS variables in `style.css`

## Features

- Smooth page transitions with fade animations
- Responsive design for mobile and desktop
- Light pink color theme
- Contact form with basic validation
- No build tools or dependencies required

## Customization

### Update Your Information

In `index.html`:
- Change "Portfolio" to your name in the logo
- Update "[Your Name]" and bio in the About section
- Edit project details in the Projects section
- Update experience and education in Resume section
- Add your contact details and social links

### Change Colors

Edit the CSS variables at the top of `style.css`:
- `--pink-50` through `--pink-900` - Pink color shades
- `--neutral-50` through `--neutral-900` - Gray color shades
